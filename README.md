# ItzAkshaj Portfolio

A responsive, cinematic 3D-inspired personal portfolio built with plain HTML, CSS and JavaScript. No build step or package installation required.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub + Vercel (Android)
1. Sign in to GitHub in your browser and create a new **public** repository named `itzakshaj-portfolio`.
2. Choose **Add file → Create new file**.
3. Name the file `index.html`, paste the complete contents of this project's `index.html`, and commit it to the repository.
4. Open Vercel and sign in using GitHub.
5. Select **Add New → Project**, import `itzakshaj-portfolio`, and deploy.
6. Vercel will provide a live `*.vercel.app` URL. You can use that URL to share your portfolio.
7. When you update `index.html` in GitHub and commit the changes, Vercel will redeploy automatically.

## Personalize before sharing
Search within `index.html` and replace the placeholder social destinations with your real links. The current GitHub button intentionally points to GitHub's homepage until you provide your profile URL. No email address or unconfirmed credentials are invented.

Project cards are described as concepts or work in progress where appropriate. Update them as each project becomes publicly available.
